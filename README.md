# Swift Certified User — Practice Exams

Two 100-question browser-based practice exams covering the five Swift
Certified User exam domains: Swift Language Usage, SwiftUI, Debugging,
Planning and Design, and Xcode Navigation. Practice Exam 2 is a
harder, more advanced tier — different questions throughout, not a
repeat of Exam 1.

Each exam offers two modes:

- **Practice** — untimed, with instant right/wrong feedback and an
  explanation shown after every answer.
- **Timed Exam** — the full countdown (65 seconds/question, ~108
  minutes total), no feedback until you submit or time runs out, then
  a score, topic breakdown, and a full per-question review.

Other details:

- Questions and answer options are shuffled on every attempt.
- Automatic submission when time expires.
- Previous/Next navigation plus a question palette showing progress.
- A warning before leaving mid-exam, so you don't lose progress by
  accident.

Open `index.html`. If local JSON loading is blocked (e.g. opening the
file directly), run `python -m http.server 8000` in this folder and
open `http://localhost:8000`.
