# Swift Certified User — Hard Timed Practice Exams

Two 60-question browser-based practice exams.

- 65 seconds per question
- 65 minutes total
- Countdown and automatic submission
- Previous/Next navigation
- Question palette and progress
- Score and topic breakdown
- Harder reasoning-oriented coverage

Open `index.html`. If local JSON loading is blocked, run `python -m http.server 8000` in this folder and open `http://localhost:8000`.
